# quicknotes-app
The Notes App is a clean, responsive, and secure single-page web application designed to help users efficiently capture, categorize, and manage their daily thoughts and tasks. Built with vanilla JavaScript, HTML, and CSS, it emphasizes robust input validation, dynamic state management, and strict DOM safety practices by avoiding vulnerable innerHTML rendering methods for user-generated content.
# what i learnt
Gained practical experience building UI components
Understood how maintaining a single source of truth simplifies complex operations like filtering , deleting and re-rendering.
Learned how to handle form submissions, checks gracefully, providing immediate context-aware error feedback and clearing inputs only upon successful validations
# how to run the project locally
Download the repository to your computer
Ensure the two files in the root directory, html.index and script.js as well as style.css
Open the html.index file in any modern web browser or local development server such as live server or VS Code for better experience.
